# AGENTS.md: assets/logo

How the app's logo and icons are made. The rules in the root [AGENTS.md](../../AGENTS.md) still apply.

**Prime rule: the `*.svg` masters here and everything in `../icons/` are build outputs.** Never hand-edit them. Change a constant in `build_logo.py` and rerun; the scripts and `source/` are the single source of truth.

## Why parametric, not traced
The source (`source/logo-src.png`, 1254x1254, generated by an image model) is flat geometry: a navy rounded tile with 19 circles and diamonds on a 5x5 grid, in a band around the anti-diagonal (`|row - (4 - col)| <= 2`). Tracing would turn exact circles into wobbly splines. Instead `measure_source.py` measured each shape once, and `build_logo.py` redraws them as exact `<circle>` and rotated `<rect>` primitives, about 2 KB per master.

Deliberate changes from the source:
- the shapes sit on a uniform square grid and the composition is centred (the source drifts: column pitch 182-210 px, row pitch 169-176 px, and it sits off-centre);
- a separate small variant redraws the same band on a 3x3 grid, because at 16-32 px 19 shapes blur into noise.

Kept as in the source: which cell is a circle or a diamond, each shape's size, each shape's colour (sampled medians), the navy `#00163D` and the corner radius (0.207 of the side).

## Toolchain
| Tool | Install | Role |
|---|---|---|
| resvg | `cargo install resvg` | SVG to PNG |
| uv + Pillow | `uv` on PATH | measuring, generating, ICO/ICNS writing: `uv run --with pillow python <script>.py` |

## Pipeline
```sh
cd assets/logo
uv run --with pillow python measure_source.py   # only when the source changes; copy results into CELLS
uv run --with pillow python build_logo.py       # writes the four SVG masters
uv run --with pillow python export_icons.py     # writes ../icons/ and build/compare.png
```
After every run, look at `build/compare.png`: the source, then the four masters, then 16, 24, 32, 48 and 64 px at 1x and enlarged 4x.

## Outputs
| File | Use |
|---|---|
| `logo.svg` | full-bleed tile: Linux `hicolor/scalable`, the source for 48 px and up |
| `logo-small.svg` | 3x3 variant, the source for 16, 24 and 32 px |
| `logo-macos.svg` | 824 px tile in a 1024 canvas, Apple's icon grid (macOS applies no mask of its own) |
| `logo-mark.svg` | the shapes alone, transparent, for use inside the app |
| `../icons/icon-<n>.png` | 16 to 1024 px: hicolor sizes and the window icon |
| `../icons/icon.ico` | Windows, 16 to 256 px, each frame from its own render |
| `../icons/icon.icns` | macOS, from `logo-macos.svg` |

`build/` is disposable and gitignored.
